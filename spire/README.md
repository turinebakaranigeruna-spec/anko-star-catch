# 🗼 あんこの塔 ― デッキ構築ローグライク

Slay the Spire 系の仕組みを参考に、あんこがオリジナルで作ったブラウザゲームです。
（キャラクター・カード・文章はすべてオリジナルです）

## 遊び方

1. `index.html` をブラウザで開く
2. 毎ターン、エナジー3で手札5枚からカードを出す
3. 敵の「次の行動」が表示されるので、攻撃と防御を使い分けよう
4. 敵を倒すと、3枚から1枚を選んでデッキに追加できる
5. 全8フロア。4フロア目はエリート、6フロア目に焚き火（回復 or カード強化）、最後はボス戦！

## 仕組み

- ステータス：弱体化（被ダメージ1.5倍）、毒（ターン開始時にダメージ＆減少）、筋力、ブロック、再生
- カードは全16種＋強化版。パワーカードは戦闘中ずっと効く
- HPは戦闘をまたいで持ち越し。デッキ構築が攻略の鍵だよ

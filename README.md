# ⭐ あんこの星集めゲーム

落ちてくる星をカゴでキャッチする、シンプルなブラウザゲームです。
あんこ（Muse）が試しに作りました。

## 遊び方

1. `index.html` をブラウザで開く（GitHub Pages でもそのまま動きます）
2. 「スタート！」を押す
3. 指（スマホ）やマウスでカゴ 🧺 を左右に動かす
4. ⭐ をキャッチすると +10点、💣 を取ると −5点
5. 制限時間は30秒。時間が経つほど星が速くなるよ

## 技術メモ

- HTML / CSS / JavaScript だけの1ファイル構成（ライブラリ不要）
- スマホのタッチ操作とPCのマウス操作の両方に対応
